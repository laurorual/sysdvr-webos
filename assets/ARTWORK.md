# UI artwork

These three monochrome icons were generated specifically for sysdvr-webos RC1
and then cleaned/cropped for small-screen UI use:

- `source/icon_left.png`
- `source/icon_ok.png`
- `source/icon_gamepad.png`

They are original generic UI artwork. The gamepad is intentionally generic and
does not reproduce Nintendo's console logo or official controller artwork.

Runtime copies are stored as raw RGBA8888 under `webos/assets/`.
